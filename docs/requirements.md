# 需求与验收清单

更新日期：2026-11-01。依据《Android 课程设计 · 选题与开发指南》第 2–11 页及选题登记的功能分配整理。实现方案属于本项目设计，验收要求以课程指南为准。

## 一、已确定的范围

- 主 App：B4 单词记忆。
- 伴生模块：P1 桌面小组件。
- 个性化必做：智能间隔复习、学习统计与进度分析。
- 个性化自选：单词本导入与导出。
- 原生 Android，使用 Kotlin。独立完成，允许 AI 辅助，学生须理解关键代码。
- 不扩展为第二个完整 App。初版以离线学习为主。

## 二、通用最低标准（指南第 3 页）

| 编号 | 要求 | 计划实现 | 验收证据 |
|---|---|---|---|
| G1 | 至少 4 个界面，列表到详情导航 | 首页、词本、单词列表、详情、学习、复习、测试、统计、设置 | 实际导航演示 |
| G2 | 数据持久化 | Room 保存业务数据，DataStore 保存偏好 | 重启进程后数据仍在 |
| G3 | 真实 API、设备能力、后台任务至少一项 | WorkManager 检查复习任务、触发提醒 | 实际后台任务执行与状态记录 |
| G4 | 协程、ViewModel 与生命周期处理 | 异步数据库操作、生命周期感知的数据收集 | 页面切换和重建无重复写入或主线程阻塞 |
| G5 | 权限申请及拒绝后的降级 | 在需要时请求通知权限，拒绝后保留首页与小组件任务入口 | 拒绝权限后核心流程可用，无反复强迫授权 |
| G6 | 自定义业务逻辑 | 间隔复习算法与学习统计 | 算法测试、同词不同反馈得到不同安排 |
| G7 | 加载态、空态、错误态 | 无词库、无待复习、损坏导入文件、后台失败等状态 | 真实异常场景截图与操作记录 |

注意：第 9 页第 5 次实验检查点提到“网络或设备能力”，第 3 页允许以后台任务满足硬能力。选题审核时说明本项目以后台任务覆盖该要求；如教师另有口径，再调整范围。

## 三、B4 与个性化功能

| 编号 | 功能与来源 | 验收标准 |
|---|---|---|
| W1 | 遗忘规律与复习算法（B4、个性化必做） | 算法独立于界面；根据历史及反馈更新状态和下次到期时间；可解释设计依据 |
| W2 | 复习队列（B4） | 只选到期词；完成后重新计算；重复点击不会重复计数；跨日与无到期词可处理 |
| W3 | 词库导入（B4、个性化自选） | 系统文件选择器选取 CSV；校验字段与空值；重复策略明确；输出成功、重复、失败数量 |
| W4 | 测试模式（B4） | 完成一轮试题、评分、展示错题；记录真实测试结果 |
| W5 | 通知（B4 强制技术点） | 提醒可配置；有任务才提醒；点击进入对应页面；通知权限拒绝时可继续使用 |
| W6 | 学习统计与进度分析（个性化必做） | 展示真实学习量、复习量、测试正确率、连续学习天数、词本进度；明确统计口径 |
| W7 | 词本导出（个性化自选） | 导出 CSV 后可重新导入，中文、逗号、引号、换行可正确处理 |

初版词表字段：word（必填）、meaning（必填）、phonetic、example、exampleTranslation。导出范围为词条，不包含学习记录备份。

测试模式采用选择题，词条不足以生成干扰项时提示补充词库，不生成重复选项。初版测试仅记录成绩，复习反馈单独驱动调度算法。

复习算法采用分阶段间隔策略，按回答情况调整阶段，遗忘时缩短间隔。参数在算法模块开发时确定，并测试到期时间、连续答对、遗忘和跨日情况。该策略用于安排复习，不用于测定个人记忆概率。

## 四、P1 桌面小组件（指南第 6 页）

- 使用 AppWidget / RemoteViews，从手机主屏添加，独立展示核心数据。
- 显示今日学习进度与待复习数量，提供学习和复习入口。
- 读取主 App 的真实数据库；学习完成后刷新，后台任务和日期切换时考虑更新。
- 点击进入对应页面或学习队列；无数据时提供明确引导。
- 检查多个组件实例、应用进程不在前台、跨日、无词库等场景。
- 放在同一 Android 工程下独立的 widget 包和资源目录，文档、提交记录及演示单独可追溯。不需要单独 APK。
- 不承诺秒级后台刷新或精确定时通知；后台更新受到系统调度限制。

## 五、数据模型草案

| 数据 | 用途 |
|---|---|
| WordBook | 词本名称、来源、创建时间 |
| Word | 归属词本、词形、释义、音标、例句 |
| LearningState | 单词学习状态、复习阶段、下次到期时间、最后学习时间 |
| ReviewLog | 学习或复习事件、反馈、时间、变更前后阶段 |
| TestSession / TestAnswer | 测试会话、答案与评分 |
| DataStore 偏好 | 每日目标、提醒时间与开关 |

词条与学习状态分离；统计优先基于事件记录，避免重复写入导致虚增。日期、时区和“今日”的统计规则需统一。
