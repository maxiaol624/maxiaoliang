# 学习统计

入口为首页「查看学习统计」。数据来自本地实际学习记录与测试结果，数据库当前为版本 4。

## 计算规则

| 指标 | 计算方法 |
| --- | --- |
| 今日新学 | 今日提交首次学习反馈的词条数，同一词条只计一次 |
| 今日复习 | 今日提交的到期复习反馈次数，同一词多次到期复习分别计数 |
| 连续学习 | 今天有记录就从今天向前查，否则从昨天查，遇到空白日停止。新学、到期复习或完成整轮测试均算有学习记录 |
| 待复习 | 已学词中，下次复习时间小于或等于当前时间的词条数 |
| 已学比例 | 已提交首次反馈的词条数 / 词本总词数，百分比取整数，空词本显示 0% |
| 近 7 天 | 按手机当前时区归属自然日，从 6 天前至今天分别显示新学和复习量，空白日补零 |
| 复习阶段 | 0–1 档为需加强，2–3 档为巩固中，4–5 档为长间隔，反映当前排程 |
| 测试表现 | 显示今日与累计完成轮数，正确率为全部已完成测试的答对题数 / 总题数，取整数 |

「再练一遍」只翻看已学词，不写入学习事件，因此不增加新学量、复习量或连续学习天数。已学比例不等同于掌握率。

修改手机时间后可能出现未来时间的学习记录。统计会等当前时间达到记录时间再计入。更换时区时，历史记录按新的时区重新归属日期。日期计算使用 `LocalDate`，跨日按日历推进，不假设每天一定是 24 小时。

测试按完成时间归属日期，中途未答完的轮次不计入。无测试时显示提示，避免把缺少记录解释为正确率 0%。多轮正确率按总题数加权计算。

## 实现

- `StatisticsDao` 在同一个 Room 事务中读取词本、词条学习状态、复习事件时间和测试成绩，保证一次统计使用一致的数据快照。
- `StatisticsCalculator` 是独立的计算类，接收数据快照、当前时间和时区，输出统计结果，便于测试跨日和连续天数规则。
- `StatisticsViewModel` 监听数据库变动。页面可见期间检查日期和到期时间，离开页面后停止监听与计时。计算在后台执行，仅在结果变化时更新页面。
- `StatisticsActivity` 展示统计卡片、趋势条和词本进度。页面有加载、空词库和失败重试状态，词本卡片可进入对应词本。
